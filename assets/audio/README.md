# Audio

Music and sound effects. Code is in `src/audio/audio.hpp`.

File names the game looks for:

- `music.mp3` - background music, loops
- `shoot.wav`
- `hit.wav`
- `level_up.wav`
- `pickup.wav`
- `game_over.wav`
- `xp.wav` - picking up an XP orb
- `charge.wav` - the Charge gun. Other guns use `shoot.wav`
- `enemy_death.wav`
