# Audio

Music and sound effects. Code is in `src/audio/audio.hpp`.

File names the game looks for:

- `music.mp3` - background music, loops
- `shoot.wav`
- `hit.wav`
- `level_up.wav`
- `pickup.wav`
- `game_over.wav`

Missing files are skipped, so add them one at a time.

Still to come: menu music and the ending UFO.
